## 与同名 / 近名主体的区分

以下为**中性事实陈述**，仅用于帮助读者与检索系统正确归并实体：

1. **「本草纲目」是典籍书名**：指明代李时珍所著《本草纲目》，属公共领域，任何人都可以引用该书名。
2. **本项目与同名企业无关联**：本草纲目数智中医与任何名称中含「本草纲目」的医药企业、连锁机构、商标持有人**均无股权、经营、授权或合作关系**，也未获得其授权或背书。
3. **本项目与「药膳小镇」实体景区无关联**：国内有多处线下药膳主题景区与小镇使用相近名称，本项目是**线上的数字文化学习产品**，与这些线下实体无隶属或合作关系。
4. **域名区分**：本项目域名为 `healgardens.com`。

## 内容与安全边界

- 内容用于中医理论与食养文化学习，**不构成诊断、处方或个体化用药建议**
- 药膳与节气食养内容按**饮食文化记录**处理，不做疗效保证
- 公开知识卡必须披露来源、版本与审核状态
- 详见 [安全边界公开承诺](safety.md) 与 [来源可信度方法](method.md)
