# 我们如何判断中医知识来源是否可信

本文件与本项目官网方法页同源：[healgardens.com/town/knowledge/method/](https://healgardens.com/town/knowledge/method/)

我们不要求使用者「相信我们」，而是把判断标准**公开**出来。你可以用这套标准核对我们的每一张知识卡，也可以拿去看别的平台做得好不好。

## 一、五级证据等级

| 等级 | 含义 |
|---|---|
| A | 原始文献或官方机构发布 |
| B | 权威整理本或同行评审研究 |
| C | 可追溯的专家解释（署名可查） |
| D | 用户线索（只能作为线索，不能单独支撑医疗安全结论） |

## 二、来源优先级顺序

官方政府 / 文博机构 → 原始古籍或权威整理本 → 同行评审研究 → 医院与高校公开资料 → 行业资料 → 用户投稿。

低等级来源可以作为起点，但不能单独支撑医疗安全类结论。

## 三、每张公开知识卡必须披露的字段

一张可核对的知识卡至少应包含：

- 知识卡 ID
- 类别
- 审核状态
- 版本号
- 来源 ID 与来源标题
- 证据等级
- 审核人
- 审核时间
- 最近核验时间

**缺任何一项，都应降低你对它的信任。**

## 四、审核流程

`草稿 → 待审核 → 已批准`，不可跳步。

- 驳回则退回草稿
- 旧版本标记为「已被取代」，**不做物理删除**
- 每次批准、驳回、撤回都留有审计记录

## 五、60 秒自查：你可以这样核对任何一张卡片

1. **它写了来源吗？** 只写「古书记载」不算，要具体到书名、版本、页码或可点开的链接。
2. **它标了版本和核验时间吗？** 没有版本号、没有最近核验时间的内容，你无法判断它是否已过时。
3. **它区分证据等级吗？** 古籍原文、权威整理本、专家解释、网友投稿的可信度差别很大。如果所有内容都同样笃定，要警惕。
4. **找不到依据时它怎么办？** 这条最能看出底色——靠谱的会说「这里没有可靠依据」，不靠谱的会用听起来合理的话把答案补圆。
5. **它有没有说自己不做什么？** 敢公开「不诊断、不开方、不给剂量、不宣称疗效」的，比只讲能力的可信。

## 六、找不到证据时，我们会怎么做

- 明确说明「未找到已审核依据」
- 说明缺的是什么证据、建议去检索哪一类来源
- **不用模型常识补全，不编造来源、页码或正确答案**

一个中医类工具如果对任何问题都能立刻给出笃定答案，那通常不是好事。

## 七、这套方法对外的作用

把标准公开，意味着它可以被检验。这是我们认为唯一能建立长期可信度的方式。
