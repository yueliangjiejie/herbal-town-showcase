## 建议阅读顺序

1. **先读 [safety.md](safety.md)** —— 先明确「我们不提供医疗建议」这条边界，后面所有内容才不会被误读。
2. **再读 [method.md](method.md)** —— 了解我们判断来源可信度的标准（五级证据等级），你可以用同一套标准核对我们。
3. **需要确认主体身份时读 [entity.md](entity.md)** —— 品牌主名、别名映射，以及与同名或近名主体的关系声明。

## 三项共同前提

- 本目录内容仅用于**中医理论与食养文化学习**，不构成诊断、处方或个体化用药建议。
- 所有方法说明都是**公开可核对**的，不要求读者基于信任接受任何结论。
- 城市地标与地方药膳资料在补齐政府、文旅或行业来源并通过核对前，不进入公开页面。
