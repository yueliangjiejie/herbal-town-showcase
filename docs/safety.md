# 我们不做什么：安全边界公开承诺

本文件与本项目官网承诺页同源：[healgardens.com/town/safety/](https://healgardens.com/town/safety/)

## 七条公开承诺

1. **不诊断** —— 不做体质辨证结论，不出具任何诊断性判断
2. **不开方** —— 不提供方剂、配伍或用药建议
3. **不给剂量** —— 不给出「每天几克」这类用量指导
4. **不做个体化用药建议** —— 不针对某个人的身体状况给出建议
5. **不宣称疗效** —— 不对任何内容做治疗效果承诺
6. **不卖货** —— 不销售药材、食品或课程，内容不挂购买链接
7. **不收集个人健康信息** —— 不保存使用者的个人健康描述

这七条是公开承诺，欢迎随时对照检查我们有没有食言。

## 遇到这些情况，我们会怎么做

| 情形 | 我们的处理方式 |
|---|---|
| 询问「我这种情况能不能吃」 | 不回答个体化问题，说明这属于诊疗范畴，建议咨询执业医师 |
| 询问具体剂量 | 不提供剂量，说明剂量需由医师根据个体情况判断 |
| 询问急症处理 | 引导立即联系急救或前往正规医疗机构 |
| 涉及孕期、儿童、过敏 | 不给出个体化建议，建议就医 |
| 讨论药材、方剂的一般知识 | 可以使用**已审核的证据**做文化与传统理论层面的介绍，不补写证据之外的内容 |

## 药膳内容的准确定位

药膳、节气食养内容的定位是**饮食文化记录**——记录「什么人、在什么地方、按什么时令这样吃」。

它有文化价值，但这个价值与「吃了能治病」是两件事。把前者说成后者，才是对传统的不尊重。

因此：

- 我们记录做法、来历与地域背景
- 我们**不做**功效保证
- 我们不对特定人群推荐食用

## 为什么我们不卖货

一旦开始销售药材或课程，所有内容都会被使用者重新解读为销售话术。即使后面讲得再准确，可信度也已经损耗。

所以我们把商业边界放在内容之外。

## 常见做法 vs 我们

| 常见做法 | 我们 |
|---|---|
| 输入症状给结论 | 不做诊断，引导到正规医疗机构 |
| 讲完药膳挂购买链接 | 不卖货 |
| 用模型常识补全答案 | 无证据时明说「未找到已审核依据」 |
| 内容不标来源 | 每张卡披露来源、版本、审核状态 |
| 保存用户健康描述 | 不收集个人健康信息 |
