# 本草纲目药膳小镇

本草纲目药膳小镇是一个以城市地标、地方药膳和本草文化学习为主题的像素互动项目。

在线体验：[https://healgardens.com/town/](https://healgardens.com/town/)

## 项目内容

- 像素小镇与城市漫游
- 南宁、桂林、防城港、玉林城市展示
- 药材、药膳、节气与地标学习任务
- NPC 文化学习对话
- 家乡药膳记录与审核发布
- 经方医馆同域入口

## 内容与安全边界

- 项目用于本草文化、药膳文化和经方知识学习，不替代执业医师诊断。
- NPC 不提供处方、个体化剂量或治疗效果承诺。
- 药膳、药材和城市资料需保留来源，并经审核后才能进入公开知识层。
- 用户、商家和厂家投稿不会未经审核直接公开。

## 当前状态

项目处于测试与内容建设阶段。生产源码、数据库、服务器配置、模型密钥以及未审核原始资料不在本公开展示仓库中。

## 参与方式

欢迎通过 GitHub Issues 提交：

- 城市地标和地方资料线索
- 有可靠来源的地方药膳资料
- 页面问题与改进建议
- 无障碍、移动端和交互体验反馈

提交资料时请注明来源、授权状态和适用地区。请勿提交个人健康资料、诊断记录、处方或 API Key。
