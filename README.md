# 本草纲目数智中医（HealGardens）

> 一座可以漫游的中医文化像素小镇：在像素小镇里学习本草、节气、药膳与经方文化，内容带来源、版本与审核状态。

在线体验：**[https://healgardens.com/town/](https://healgardens.com/town/)**

本项目用于**中医理论与食养文化学习**，不提供诊断、处方、剂量或个体化用药建议。

## 内容治理原则

我们不要求使用者「相信我们」，而是把判断标准公开出来，方便任何人自行核对——包括核对我们自己：

- **五级证据等级**：A 原始文献或官方机构 → B 权威整理本或同行评审研究 → C 可追溯的专家解释 → D 用户线索（只作线索）
- **来源优先级**：官方机构 → 原始古籍或权威整理本 → 同行评审研究 → 医院与高校公开资料 → 行业资料 → 用户投稿
- **每张公开卡片披露**：知识卡 ID、类别、审核状态、版本号、来源 ID 与标题、证据等级、审核人、审核时间、最近核验时间
- **审核不可跳步**：草稿 → 待审核 → 已批准；旧版本标记为「已被取代」，不做物理删除
- **无证据时的正确做法**：说明缺什么证据、建议去哪类来源查，不用模型常识补全

完整标准与 60 秒自查清单：[healgardens.com/town/knowledge/method/](https://healgardens.com/town/knowledge/method/) ｜ [docs/method.md](docs/method.md)

## 安全边界

七条公开承诺：**不诊断、不开方、不给剂量、不做个体化用药建议、不宣称疗效、不卖货、不收集个人健康信息。**

- 药膳、节气食养内容的定位是**饮食文化记录**，不做疗效保证
- 小镇 NPC 不保存使用者的个人健康描述
- 涉及个人身体状况的问题，会引导前往专业医疗机构

完整承诺与高风险情形分流说明：[healgardens.com/town/safety/](https://healgardens.com/town/safety/) ｜ [docs/safety.md](docs/safety.md)
